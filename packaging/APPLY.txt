The English site, as a replayable patch series
==============================================

Why patches and not a push: this session's GitHub credentials get a 403
on arturkryzan/gravity-integration-site, so nothing here can reach it.
These patches carry the identical work; you apply them in your own clone
and push from there.

There are two folders. Apply ONE of them, not both.


Which one do I need?
--------------------
In your clone, run:

    git log --oneline -8

Look for "Translate the rest of the content: commercial, proof,
conversion".

  You have it        →  use  new/   (11 patches — everything since)
  You don't have it  →  use  full/  (15 patches — the whole English build)

Hashes will differ from mine; git am replays diffs, not hashes, so a
different hash for the same commit message is expected and harmless.

Until 0005 lands, the English pages build but carry noindex, stay out of

the English site on.

slider now starts at "1500" rather than "1 500" — Polish doesn't group
four-digit numbers, so the calculator's own JS has always rendered 1500
the instant you touch the slider, and only the static label disagreed.
Both come from the same formatter now. The commit message has the
measurements.

the packaged archive looking for Polish text left on English pages.

0011 puts the English site in euro — 0, 799 and 1,799 — and leaves the
Polish one on 2999 and 7999 PLN. Two deliberate loose ends ride along
with it, both spelled out in its commit message: the Stripe Buy buttons
still point at the PLN checkouts until you set the euro prices up there,
and the ROI calculator is still denominated in PLN because relabelling
its sliders without rescaling them would make it compute nonsense.

To apply and push
-----------------
    git status                      # must be clean before git am
    git am /path/to/new/*.patch     # or full/*.patch
    git push

If git am stops on a patch you already have, `git am --skip` steps over
it. To back out entirely at any point: `git am --abort`.


One expected warning
--------------------
git reports "trailing whitespace" once, in Footer.astro. That is
deliberate — the tab indentation is load-bearing in the rendered output.
Apply it as-is; don't let an editor strip it.
